# 订婚宴邀请网页 · v3.0

这是一个“手机优先”的单页邀请函，包含开场载入、倒计时、滚动动效、粒子花瓣、照片画廊、一键放大、复制地址和回执分享等功能。文案与联系方式集中在 `config.js`，照片已替换为吕志方与胡珊珊本人的合影。

当前正式入口是 `index-luxe.html`，根目录 `index.html` 会自动跳转到 3.0 版本。GitHub Pages 分享地址：

`https://anqilike.github.io/engagement-invitation/index-luxe.html?v=3.0`

`index-current.html` 仅作为旧版存档，不再作为正式入口。

## 3.0 更新

- 修复桌面端首屏“我要赴约 / 先看看照片”按钮不可见的问题。
- 新增可用的回执交互：选择出席情况、填写姓名/人数和备注，然后通过系统分享或复制回执发送给邀请人。
- 移除照片区的高度预判，避免桌面端滚动时页面突然跳动。
- 新增 960px / 1280px 高清预览图，并压缩放大原图，桌面端照片更清晰。
- 优化载入动画、低端手机动效性能、菜单关闭图标、文字可读性和键盘操作。
- 增加安装图标、正确的 PWA 启动地址、分享卡片地址和 `noindex` 设置。

## 本地预览

这一步不是托管，只是在电脑上先看效果：

```powershell
python -m http.server 4173
```

然后浏览器打开 `http://localhost:4173`。

也可以直接双击 `index.html`，但在手机真实测试或部署之前建议使用本地服务器。

## 修改内容

1. 打开 `config.js`，可修改姓名、日期、地点、回执截止时间和联系方式。
2. 如需在线问卷，把问卷链接填到 `config.rsvpUrl`；不填时会使用系统分享或复制回执。
3. 如需显示电话或微信，填写 `config.contactPhone` 和 `config.weixinId`。
4. 如需更换照片，把新照片放入 `assets/photos/`，保持原来的文件名，或同步修改 `index-luxe.html` 里的图片路径。
5. 修改 `index-luxe.html` 中照片卡片的 `alt` 文案。

## 免费托管建议

这个页面是纯静态文件，不需要服务器。推荐：

- **Netlify Drop**：打开 https://app.netlify.com/drop ，把整个文件夹拖进去即可获得公开链接。最简单，几分钟完成。
- **GitHub Pages**：把项目推到 GitHub 仓库，在 Settings → Pages 中选择分支即可。免费、稳定，适合长期使用。
- **Vercel / Cloudflare Pages**：拖拽或连接 GitHub 自动发布，国内访问速度通常也不错。

如果想要自定义域名（例如 `love.example.com`），以上平台都可以配置免费域名或域名绑定。
